# Machine Learning From Scratch

A personal project to build machine learning algorithms from scratch using Python and NumPy.

## Objective

The goal of this repository is **not** to compete with libraries like scikit-learn.

The objective is to understand how machine learning algorithms work internally by implementing them from first principles.

Rather than treating models as black boxes, I want to understand:

* Why an algorithm works
* How each mathematical concept translates into code
* The tradeoffs behind implementation decisions
* Common failure modes and limitations

Every implementation is built with learning as the primary objective.

---

## Why This Project?

Machine learning libraries make it easy to train models with only a few lines of code.

While this is excellent for production, it often hides the mechanics of what is actually happening.

This repository focuses on rebuilding those mechanics from scratch to develop a deeper understanding of:

* Decision Trees
* Regression algorithms
* Classification algorithms
* Unsupervised learning algorithms
* Ensemble methods
* And additional models as the project grows

---

## Secondary Goals

This project is also an opportunity to improve software engineering skills alongside machine learning.

Areas of focus include:

* Writing clean and maintainable Python code
* Object-oriented design
* Code organization and modularity
* Validation and error handling
* Logging and debugging
* Project structure and scalability

The repository is expected to evolve continuously as both my machine learning knowledge and software engineering skills improve.

---

## Philosophy

This project prioritizes **understanding over optimization**.

The implementations are intentionally written to maximize clarity instead of minimizing runtime.

Once the underlying concepts are fully understood, optimizations and performance improvements can be explored separately.

---

## AI Usage

AI has been used selectively as a learning and productivity tool.

Examples include:

* Improving documentation
* Refining logging messages
* Discussing software design decisions

However, the machine learning algorithms, implementation logic, debugging process, and design decisions are intentionally developed as part of my own learning process.

Some implementations may not be the most optimized or production-ready because the primary objective is educational rather than performance.
